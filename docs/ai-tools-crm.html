5 · 이어서 할 일

① 금액 32건 채우기 다음 작업

Claude 새 대화창에서 영수증·카드명세서를 붙여넣고 "이거 기록해줘" 라고 하면 됩니다. "이번 달 AI 비용 얼마야?" 로 조회도 됩니다. 기록하면 /ai-services 화면에 바로 반영됩니다.

아직 확인 안 된 것 — 실제로 결제가 저장되는 것까지는 검증하지 못했습니다. 테스트로 가짜 결제를 넣으면 지우는 기능이 없어 재무 기록에 영구히 남기 때문입니다. 읽기와 수정(update_tool)은 실호출로 확인했고, 결제 저장도 같은 방식이라 통과해야 맞습니다. 첫 실제 영수증 기록이 최종 확인이 되며, 실패하면 ai-tool-payments Blob 생성 부분을 보면 됩니다.

② 토큰을 다시 만들어야 할 때

Vercel 은 환경변수를 암호화 저장해 한 번 넣으면 값을 다시 꺼낼 수 없습니다 (vercel env pull 이 빈 값을 반환). 그래서 토큰을 잃어버리면 재발급밖에 방법이 없습니다.

# 1) 새 값 생성 (화면에 찍지 말 것)
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))" > /tmp/.t

# 2) 교체
vercel env rm AI_TOOLS_MCP_WRITE_TOKEN production --yes
vercel env add AI_TOOLS_MCP_WRITE_TOKEN production < /tmp/.t

# 3) Claude 에 등록 (값을 지우기 전에 먼저 할 것)
claude mcp remove ai-tools -s user
claude mcp add --transport http ai-tools \
  https://zoellife.com/api/ai-tools/mcp \
  --header "Authorization: Bearer $(cat /tmp/.t)" -s user

# 4) 재배포해야 반영된다 (약 80초)
git commit --allow-empty -m "chore: 토큰 반영 재배포"
git -c credential.helper='!gh auth git-credential' \
  push https://github.com/gai-cmd/daracheon.git main

# 5) 임시 파일 삭제
rm -f /tmp/.t

6 · 반드시 지킬 것

이 저장소는 공개(PUBLIC) 입니다. 비밀번호·API 키·토큰·2FA 백업코드를 코드·문서·시드 어디에도 넣지 마세요. 일회성 스크립트의 process.env.X ?? '실제값' 형태 폴백도 금지입니다 — 2026-07-10 에 이 패턴으로 Blob 접두어가 11주간 노출된 적이 있습니다. 커밋 전 git grep <의심값> 로 확인하세요.

계정 분리 — KAFLIX CLOUD(회사)와 개인 권역(Miraclro·try-n.com·zoellife)은 완전히 별개입니다. Account info 시트의 KAFLIX 블록(TeamPassword·Cloudsign·efax·ZOOM·PR Times·ASKUL)은 이 CRM 에 넣지 않았고, 앞으로도 넣지 않습니다.

외부 발신은 사람이 승인 — git push·배포·발행·메일 발송은 항상 최종 승인을 받고 실행합니다. 로컬 커밋·빌드·테스트·조회는 바로 진행해도 됩니다.

알아두면 덜 헤매는 것들

  • Vercel 환경변수는 재배포해야 반영됩니다. 등록 직후엔 계속 401 이 납니다 (약 80초 소요).
  • Blob 이 정본입니다. data/db/*.json 만 고치고 푸시하면 프로덕션 데이터는 그대로입니다.
  • 인자 이름이 통일돼 있지 않습니다 — update_tool 은 id, log_payment 는 tool_id. Claude 는 알아서 맞추지만 직접 호출할 땐 주의.
  • 푸시 403 이 나면 gh auth switch --user gai-cmd 를 먼저 하세요.
  • 화면이 안 바뀌면 캐시입니다. URL 뒤에 ?v=2 를 붙여 확인하세요.
