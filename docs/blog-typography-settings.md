# 대라천 블로그 타이포그래피 세팅값

> 기준일: 2026-08-13 · 대상: zoellife.com/blog 발행 화면 + 관리자 에디터(TinyMCE)
> 소스: `src/app/blog/[slug]/BlogArticle.module.css`, `src/components/admin/editor/TinyMCEEditor.tsx`

블로그에 글을 올릴 때 폰트·크기·색을 통일하기 위한 현재 세팅값 정리입니다.
**에디터에서 따로 크기·색을 지정하지 않으면 아래 값이 자동 적용됩니다** — 즉,
블록 서식(본문/제목 1·2·3/인용/코드)만 골라 쓰면 사이트 전체와 톤이 맞습니다.

## 4. 사진 캡션(사진설명) 사용법

1. 에디터에서 이미지를 클릭하면 뜨는 퀵바(또는 상단 툴바)의 **말풍선 아이콘
   (이미지 캡션 넣기/빼기)** 을 누르면 이미지 아래에 캡션 입력칸이 생깁니다.
2. `캡션을 입력하세요` 자리에 사진설명을 입력합니다.
3. **입력하지 않으면(비워두거나 플레이스홀더 그대로면) 발행 화면에는 아무것도
   나타나지 않습니다** — 저장·렌더 시 자동 제거됩니다.
4. 이미지 대화상자의 "캡션 표시" 체크박스도 동일하게 동작합니다.

## 5. 에디터(TinyMCE) 설정값

| 항목 | 값 |
|---|---|
| 블록 서식 목록 | 본문(p) · 제목 1(h1) · 제목 2(h2) · 제목 3(h3) · 인용(blockquote) · 코드(pre) |
| 글자 크기 선택지 | 12 / 14 / 16(기본) / 18 / 20 / 24 / 28 / 32px |
| 글자 색 팔레트 | 골드 `#D4A843` · 연골드 `#E8C97A` · 크림 `#FDFBF7` · 밝은 회색 `#C9C4B8` · 레드 `#E06A5A` · 살구 `#F0A98E` · 그린 `#8FBF8F` · 블루 `#8FB8E0` |
| 이미지 업로드 | 붙여넣기·드래그·파일선택 모두 Vercel Blob 자동 업로드 (외부 CDN 금지 정책) |
| 영상 | YouTube URL 붙여넣기 → 16:9 임베드 자동 변환 |

### 색을 고를 때 주의 — 명도 정규화

발행 시 자동 보정이 한 번 돕니다 (`lib/blog/theme-normalize.ts`):

- **어두운 글자색** (휘도 0.35 미만 — 검정·짙은 갈색 등) → **발행 화면에서 제거**
  (다크 배경에 묻히기 때문). 에디터 팔레트가 밝은 톤 위주인 이유입니다.
- **밝은 배경색** (휘도 0.5 초과) → 제거 (다크 테마와 충돌).
- 표의 골드 헤더(`#b88c2d` 배경 + 흰 글자)처럼 다크에서 의도된 조합은 유지.

즉, **글자색은 팔레트 8색 안에서 고르는 것이 안전**하고, 색을 지정하지 않으면
기본값(본문 흰색 72%, 제목은 위 표의 색)이 적용됩니다.

## 6. 요약 — 통일을 위한 실전 규칙

1. 크기·색을 손대지 말고 **블록 서식만** 사용한다 (본문/제목 1·2·3/인용/코드).
2. 강조는 **굵게**(흰색으로 밝아짐) 또는 팔레트의 골드를 쓴다.
3. 섹션 구분은 제목 2(골드 명조), 소구분은 제목 3(흰 명조)을 쓴다.
4. 사진에는 캡션(사진설명)을 입력한다 — 안 쓰면 표시되지 않으므로 부담 없음.
5. 글자 크기 선택지는 표·주석 등 예외 상황에만 쓴다 (기본 16px 유지).
